# PregNut SEO audit implementation — October 7, 2026

Top Foods now includes its default calcium/processed rankings, nutrient filters,
category links and explanatory text in the initial HTML. This prevents the
confirmed layout shift caused by inserting them into empty containers after
load. The same 72 food links remain available without JavaScript and on failed
data requests. Filters enable after initialization; selected nutrients/sources,
saved preferences, browser history and canonical consolidation remain supported.

The shared layout preloads the existing Geist font and defers ordered browser
scripts. Existing copy, images and design are preserved except for the audited
kale guidance. That entry now uses exact historical dataset figures and attaches
the relevant source to each paragraph instead of asserting fetal-development
benefits or guaranteed elimination of microbes. Both the batch source and compiled
entry are updated. This is an editorial source check, not independent clinical
review of the entire catalog.

Sources checked:

- [NIH ODS folate](https://ods.od.nih.gov/factsheets/Folate-HealthProfessional/)
- [CDC pregnancy food safety](https://www.cdc.gov/food-safety/foods/pregnant-women.html)
- The existing local food record `11234` and [data limitations](https://pregnut.com/about/#food-data-sources).

Search Console, GA4 and field CrUX were not connected in this release. The
remaining catalog's claim-specific review and owner-data opportunity selection
remain outstanding; no pages were mass-rewritten based on width heuristics,
intentional filter canonicals or partial-crawl orphan candidates.
